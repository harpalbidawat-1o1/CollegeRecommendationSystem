# College Recommendation System

A beginner-friendly Java desktop mini-project for searching colleges and viewing recommendations without student login. An Admin button on the home window will provide direct access to college-related record management; no login system is planned.

## Technologies

- Java
- Java Swing
- MySQL
- JDBC

The approved database is `college_info_db`, with the existing tables `cities`, `colleges`, `courses`, `college_courses`, and `cutoffs`. The original SQL schema will be supplied separately. No replacement schema, sample college records, external APIs, or unnecessary frameworks are included in this initial structure.

Java source files are intentionally empty. Implementation and database connection configuration will be added later.
