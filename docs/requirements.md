# Requirements Checklist

## Project

- [ ] Implement the application in Java with a basic, beginner-friendly Swing GUI.
- [ ] Connect to the approved MySQL database `college_info_db` using JDBC.
- [ ] Preserve the supplied schema and its five tables: `cities`, `colleges`, `courses`, `college_courses`, and `cutoffs`.
- [ ] Use the original SQL schema when it is supplied; do not replace it or add tables, rename columns, or invent recommendation formulas.
- [ ] Do not add fabricated sample college records, external APIs, API keys, cloud services, or unnecessary frameworks.

## Student Features

- [ ] Allow students to search for colleges without logging in.
- [ ] Allow students to view recommendations without logging in.
- [ ] Keep screens and interactions simple and beginner-friendly.

## Admin Features

- [ ] Provide an Admin button on the Home window that opens admin features directly.
- [ ] Do not add a login system.
- [ ] Support adding, viewing, updating, and deleting college-related records.

## Evaluation Concepts

- [ ] Demonstrate problem analysis and design.
- [ ] Include a clear, simple example of inheritance.
- [ ] Use Java collections where appropriate.
- [ ] Handle exceptions clearly.
- [ ] Demonstrate JDBC CRUD operations.
- [ ] Provide the Swing GUI.
- [ ] Include a simple thread example where appropriate.
